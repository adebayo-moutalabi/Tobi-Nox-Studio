# LE MATIN DE L'EXAMEN
# Script joué par le Studio. Une ligne = une instruction.
# Finir une ligne par & lance la suivante sans attendre.
#
# Personnages : TOBI, NOX
#   dit <texte>          mimique <nom>        geste <nom>
#   marche <lieu>        court <lieu>         regarde <TOBI|NOX|rien>
#   travaille            assis                dort
#   frigo                miroir               fenetre
#   leve                 prend <objet>        pose
#   utilise              donne <TOBI|NOX>     suit <TOBI|NOX>
#   seul                 sort                 danse <secondes>
#   monte <bras|epaule|sac>   descend         sortie (va à la porte, tient la poignée, sort)
#   remet (remet la gourde au frigo)     tape <texte> (s'affiche à l'écran, \n = à la ligne)
# Pour Nox, « travaille » = s'installer sur la table à côté de l'ordinateur.
# Lieux : centre tapis fenetre lit bureau armoire frigo miroir couloir porte
# Objets : papier livre gourde tasse telephone sac
# Gestes : saluer oui non epaules reflechir montrer applaudir pouce viens
#          stop gratter consterne regarder etirer saluerbas sauter victoire
# Mimiques Tobi : neutre sourire joie surprise colere tristesse doute clin degout peur dort
# Mimiques Nox  : neutre sourire joie surprise colere tristesse doute clin amour sommeil
#
# Mise en scène :
#   PLAN auto             caméra automatique : suit qui parle et qui marche
#   PLAN large|bureau|lit|fenetre|frigo|porte|miroir|clavier|ecran|tableau|dessus   plans fixes
#   PLAN gros TOBI|NOX   gros plan de face, pour une réaction ou une chute
#   DIRECT <ligne>       l'action se fait hors champ, sans temps mort
#   FONDU direct         ouvre l'image d'un coup, pour une accroche immédiate
#   ECRAN <nom du fichier>|efface       TABLEAU ligne 1 | ligne 2 | ligne 3
#   FONDU noir|ouvert    TITRE <texte>        ATTENDRE <secondes>
#   VOLET ouvert|ferme   LAMPE allumee|eteinte   PORTE ouverte|fermee
